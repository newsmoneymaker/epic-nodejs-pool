Epic Cash pool API

Public, read-only JSON API. Amounts are in atomic units: 1 EPIC = 100 000 000. Everything not listed here is closed. Публичный JSON API только для чтения. Суммы в минимальных единицах: 1 EPIC = 100 000 000. Всё, чего нет в списке, закрыто.

MethodsМетоды

GET /api/stats
Pool and network statistics: hashrate, miners, blocks, network difficulty and height, last block with its reward, pool settings (fee, ports, minimum payout).
Статистика пула и сети: хешрейт, майнеры, блоки, сложность и высота сети, последний блок и его награда, настройки пула (комиссия, порты, минимальная выплата).
/api/stats
GET /api/stats_address?address=ADDRESS&longpoll=false
Statistics of one miner: hashrate, shares, balance, paid, workers, payments. ADDRESS may be written as in the miner login: KEY@epicbox.epiccash.com, with a worker (…+rig1), with a deposit note for exchanges (…@epicbox.nonkyc.io.NOTE or #NOTE).
Статистика одного майнера: хешрейт, шары, баланс, выплачено, воркеры, платежи. ADDRESS можно писать так же, как в логине майнера: КЛЮЧ@epicbox.epiccash.com, с воркером (…+rig1), с меткой депозита для бирж (…@epicbox.nonkyc.io.МЕТКА или #МЕТКА).
GET /api/get_payments?time=UNIX_MS
Latest payments (older than time, milliseconds). A record is kernel_excess:amount:fee:0:1:block_height, the score is the payment time. The kernel excess is the transaction's identifier on the chain, the explorer shows it inside the block.
Последние платежи (старше time, миллисекунды). Запись: kernel_excess:сумма:комиссия:0:1:высота_блока, score - время платежа. Kernel excess - идентификатор транзакции в цепочке, обозреватель показывает его внутри блока.
/api/get_payments?time=9999999999999
GET /api/get_blocks?height=HEIGHT
Blocks found by the pool (older than height): time, height, hash, reward, status (pending / unlocked / orphaned).
Блоки, найденные пулом (ниже height): время, высота, хеш, награда, статус (pending / unlocked / orphaned).
/api/get_blocks?height=99999999
GET /api/get_top10miners
Top 10 miners; addresses are shortened, deposit notes are masked.
Топ-10 майнеров; адреса сокращены, метки депозита скрыты.
/api/get_top10miners
GET /api/block_explorers
Block explorer URL templates ({id} is the block height).
Шаблоны ссылок на обозреватель блоков ({id} - высота блока).
/api/block_explorers

ExampleПример

curl https://YOUR-POOL/api/stats
