About the algorithm (RandomX, Epic variant)

CPUs mine RandomX, but Epic Cash uses its own modified RandomX, not the standard one from Monero (rx/0). The Epic node's RandomX has different instruction frequencies and different AES generator keys (taken from Wownero), so the same input gives a different hash. In XMRig terms this variant is called rx/epic.

  • A miner built for standard RandomX (for example stock XMRig) will produce invalid shares on this pool: the hash does not match what the node computes.
  • Use epic-miner (official) or a miner that explicitly supports Epic / rx/epic.
  • The block header is hashed as pre_pow followed by the 64-bit nonce (big-endian); the RandomX seed is the epoch seed sent by the node with every job.
  • RandomX in fast mode needs about 2.3 GB of RAM; the pool sets the share difficulty for every miner itself (variable difficulty).

epic-miner setup

Use the official epic-miner and set these values in epic-miner.toml. Miners for the Monero protocol (XMRig and similar) are not compatible: Epic uses its own stratum protocol.

[mining]
algorithm = "RandomX"            # or "ProgPow" / "Cuckoo"
stratum_server_addr = ":"
stratum_server_tls_enabled = false
stratum_server_login = "YOUR_EPICBOX_ADDRESS+rig1"
stratum_server_password = "x"

Login formats: ADDRESS, ADDRESS+worker, and with a reward mode prefix prop:ADDRESS (shared reward, default) or solo:ADDRESS (the block finder takes the reward).

Encrypted connection (TLS): port 3334 accepts stratum over TLS. Use it if the plain port 3333 keeps disconnecting: some routers, providers and firewalls cut unencrypted mining traffic. In epic-miner.toml set stratum_server_addr = ":3334" and stratum_server_tls_enabled = true; in poolpayminer use "url": ":3334", "tls": true.

Build the miner (CPU, RandomX):

git clone https://github.com/EpicCash/epic-miner
cd epic-miner
git submodule update --init --recursive
cargo build --release                                  # CPU (RandomX)
# cargo build --release --features opencl              # CPU + GPU (OpenCL)
# cargo build --release --no-default-features --features cuda,tui   # NVIDIA GPU (CUDA)

Rewards and payments

  • Reward scheme: proportional with time weighting (older shares of a round weigh less).
  • Block rewards become spendable after 1440 blocks (about 24 hours); the pool credits your balance after that.
  • Payments are sent to your epicbox address. Mimblewimble payments are interactive, so keep your wallet online to receive them.
  • Shares of different algorithms are weighted by their probability of finding a block, so they are comparable.

Об алгоритме (RandomX, вариант Epic)

На CPU майнится RandomX, но у Epic Cash он изменённый, а не стандартный из Monero (rx/0). В RandomX ноды Epic другие частоты инструкций и другие ключи AES-генератора (как у Wownero), поэтому те же данные дают другой хеш. В терминах XMRig этот вариант называется rx/epic.

  • Майнер, собранный под стандартный RandomX (например, обычный XMRig), будет присылать на этот пул невалидные шары: хеш не совпадает с тем, что считает нода.
  • Используйте epic-miner (официальный) или майнер, в котором явно есть поддержка Epic / rx/epic.
  • Заголовок блока хешируется как pre_pow и следующий за ним 64-битный nonce (big-endian); seed RandomX - это seed эпохи, который нода присылает с каждым заданием.
  • RandomX в быстром режиме требует около 2,3 ГБ ОЗУ; пул сам задаёт сложность шар каждому майнеру (переменная сложность).

Настройка epic-miner

Используйте официальный epic-miner и задайте в epic-miner.toml. Майнеры протокола Monero (XMRig и аналоги) несовместимы: у Epic собственный stratum-протокол.

[mining]
algorithm = "RandomX"            # или "ProgPow" / "Cuckoo"
stratum_server_addr = ":"
stratum_server_tls_enabled = false
stratum_server_login = "ВАШ_EPICBOX_АДРЕС+rig1"
stratum_server_password = "x"

Форматы логина: АДРЕС, АДРЕС+воркер, а также с режимом награды: prop:АДРЕС (общая награда, по умолчанию) или solo:АДРЕС (награду получает нашедший блок).

Шифрованное соединение (TLS): порт 3334 принимает stratum по TLS. Используйте его, если обычный порт 3333 постоянно обрывается: некоторые роутеры, провайдеры и фаерволы режут открытый майнинг-трафик. В epic-miner.toml задайте stratum_server_addr = ":3334" и stratum_server_tls_enabled = true; в poolpayminer: "url": ":3334", "tls": true.

Награды и выплаты

  • Схема наград: пропорциональная с учётом времени (более старые шары раунда весят меньше).
  • Награда за блок становится доступной через 1440 блоков (около 24 часов), после этого пул зачисляет её на ваш баланс.
  • Выплаты отправляются на ваш epicbox-адрес. Платежи в Mimblewimble интерактивны, поэтому держите кошелёк онлайн, чтобы их получить.
  • Шары разных алгоритмов взвешиваются по вероятности найти блок, поэтому их можно сравнивать.
